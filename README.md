# Shaukhaloves Cake — QR-меню

Мобильное меню с категориями, поиском, карточками блюд, рекомендациями, корзиной и подготовкой заказа в WhatsApp. Есть адаптация для планшетов и компьютеров.

## Структура

- `dist/` — готовый сайт со всеми локальными ресурсами.
- `src/menu.html` — текущий исходник меню.
- `src/original.html` — первоначальная версия.
- `docs/` — заметки по интерфейсу и решениям.
- `tests/` — существующие проверки проекта.

## Локальный запуск

Из корня проекта выполните:

```bash
python -m http.server 8080 --directory dist
```

Откройте `http://localhost:8080/?table=7`. В Windows вместо `python` можно использовать `py`, в Linux/macOS — `python3`. Номер стола задаётся параметром `table` в ссылке.

Сборка и npm install для запуска готового сайта не нужны. Файлы JavaScript, шрифты, фото и иконки уже входят в `dist/`. Открывайте сайт через HTTP-сервер, а не через file://.

## Изменения

Рабочая версия для публикации — `dist/index.html`. При правках основного шаблона синхронизируйте `src/menu.html` и `dist/index.html`. Файлы историй находятся в `dist/assets/stories.js` и `stories.css`.

## Загрузка на GitHub

Распакуйте архив и загрузите содержимое папки `shaukhaloves-menu` в репозиторий. Для размещения сайта используйте содержимое `dist/` как корень сайта. Само хранение файлов в репозитории ещё не публикует сайт.
